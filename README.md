# MyFinanceTracker

A personal finance tracking application designed to help users manage their income, expenses, and savings goals effectively.

## Features (Planned)
* Track income and expenses by category.
* Set and monitor savings goals.
* Generate basic financial reports.

### Installation
This project requires the `requests` library to fetch data from a web API. To install it, we use a file called `requirements.txt`, which lists all of the project's dependencies.

1.  **First, activate your virtual environment.**
    ```bash
    source venv/bin/activate
    ```

2.  **Next, install the dependencies using pip:**
    ```bash
    pip install -r requirements.txt
    ```

## Modules
- **`stock_fetcher.py`**: This is a module that contains a reusable function to fetch real-time stock price data from the Financial Modeling Prep API. It is designed to be easily imported and used by other parts of the application. The function handles the API request, processes the JSON response, and returns the current stock price.

## Development Strategy

New features and significant changes for `MyFinanceTracker` will be developed in dedicated feature branches, ensuring that the `main` branch remains stable and always deployable.

### Workflow:
1.  **Branching:** For each new feature or significant enhancement, a new branch will be created (e.g., `feature/your-feature-name`) from the `main` branch.
2.  **Development:** All work related to that feature will occur on its dedicated branch.
3.  **Integration:** Once a feature is complete and reviewed, it will be merged back into the `main` branch.
